# Study data files

See the [repository README](../README.md) for dataset sources, the EECM timestamp correction, hashes, and the limits of this release.

- `EECM-2016_Area1_2012-2013_corrected.xlsx`: author-supplied workbook with the date year corrected from 2016–2017 to 2012–2013; measurement values are unchanged.
- `Bear_education_Austin_processed.csv`: author-supplied processed single-building BDG2 series; cite the [original project](https://github.com/buds-lab/building-data-genome-project-2) and [dataset paper](https://doi.org/10.1038/s41597-020-00712-x) when using it.
